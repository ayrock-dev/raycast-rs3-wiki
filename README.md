# RuneScape Wiki for Raycast

Search the [RuneScape Wiki](https://runescape.wiki/) directly from Raycast.

## Quickstart

```sh
pnpm i
pnpm dev
```

## Publish

To publish to the Raycast Store, set a `RAYCAST_PUBLISH_TOKEN` GitHub Actions secret with permission to fork `raycast/extensions`, push to the fork, and open a pull request.

Then, run the **🚀 Deploy** workflow manually from `main`.
